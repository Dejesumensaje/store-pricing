# Store Pricing

A store director's workspace for reviewing and acting on HQ price recommendations — accept, override, or keep current — before changes are sent to SAP.

## Quick start

```bash
npm install
npm run dev       # http://localhost:3000
npm run build     # verify production build
npx tsc --noEmit  # verify types
```
